# Sources

- Original competition data: [Name That LLM](https://www.kaggle.com/competitions/name-that-llm), Yao Yan, Martyna Plomecka, Ashley Oldacre / Kaggle, 2026. The supplied original bytes are preserved; competition terms and the original authors' rights apply. This repository does not relicense the competition data.
- Augmentation: [Name That LLM Open Pool](https://www.kaggle.com/datasets/crtproduction/name-that-llm-open-pool), crtproduction. The Kaggle metadata retrieved on 2026-11-11 declares **CC-BY-SA-4.0**. `data/augmentation_sources.csv` preserves constituent-source attribution. The Release stream is a selected, weighted derivative; construction is recorded in this repository.
- Backbone: [Qwen3-Embedding-8B](https://huggingface.co/Qwen/Qwen3-Embedding-8B), Qwen. Download the pinned revision; retain upstream license and notices. No pretrained model weights are committed here.
- Public native states, calibration, and OOF: [Name That LLM Artifacts](https://www.kaggle.com/datasets/lightningv08/ntl-olmo2-native24-final-inference-assets), lightningv08. They are downloaded from the author, verified by their manifest, and retain their original terms. The dataset metadata labels its license as `other`; this repository makes no blanket open-license claim for these assets.
- Baseline Notebook and extracted native runtime: [ntl 684 ozertuu mirror](https://www.kaggle.com/code/lbjyang/ntl-684-ozertuu-mirror), lbjyang, with ozertuu and upstream contributors credited in that Notebook. Setup downloads the original Notebook and verifies its pinned SHA256. Downloaded code is kept in ignored directories, preserving its original notices and terms.
- Public LoRA reference predictions: generated from public `dhruvtibarewal/nlm-l24-adapters-v5` q14/q8/llama members on the supplied official training rows. Their five adapter outputs and label order are provided as frozen validation inputs. `scripts/common.py` preserves the label-free adapter/fold matching and OOF stack construction. These are not hidden-test predictions and are not our newly trained model's results.

Model architecture, export layout, calibration semantics, and the complete public inference stack have substantial upstream contributions. The repository's training objective and four-device implementation should not be described as inventing those pretrained models or the public baseline.
